# 文档体系

本项目采用三种互补记录：

- `charter.md` 保存领域长期目标、边界和完成标准。
- `current.md` 汇总当前能力、证据、限制，并链接详细纪传体。
- `evolution/` 按能力维护最新完整事实，可随实现更新。
- `chronicles/` 按日期永久追加已经发生且有证据的阶段，不因后来变化而重写。
- `decisions/` 保存长期架构决定；普通修复与参数实验不进入决定记录。

教程只描述操作者应执行的任务，不复制内部架构历史。接口文档描述稳定边界、数据格式、路径和风险语义。

更新文档时必须先检查代码、配置、Git 状态和相关资源。没有实际运行的能力应写“代码已确认”或“尚未复验”，不能写成运行通过。
