# Shadow→Wuji 拇指第三版：弯曲方向与反折硬约束

日期：2026-10-14。用户授权按已讨论的方向误差、相邻指节弯曲和反折约束实施。状态：同范围第三版、有限几何修复、最终成对校验及统一审查入口全部完成。

## 范围与实现决策

沿用第二版的 59 个资产 / 236 个覆盖条目 / 172 个独立来源、原始 Wuji 一代右手、三阶段姿态与物体尺度。不补资产缺口，不覆盖第一或第二版。第二版最终选用姿态作为起点；Shadow 原姿态继续作为方向、手型和动作目标。

目标函数仍为有界最小二乘 `0.5 * ||r(x)||²`。残差不截断为 [-1,1]。新增实际指节方向与有符号弯曲的比较；真正防止末端反折依靠优化可行域和发布检查，而非只提高软权重。

模型轴初查：Shadow 的 THJ2/THJ1，以及 Wuji 的 joint3/joint4，正向扰动均使末端向几何指腹参考侧运动。Shadow 近端还有额外侧向自由度，不直接照抄全部 q。Wuji joint3/joint4 在 q=0 时的轴平面几何转角分别约 −0.4518° / −2.2356°。只有这两个末端关节建立非反折可行域，根部对掌关节不会因负 q 一律被禁止。

准备采用：将末端实际有符号几何弯曲限定为非负，同时保留机械上限；两关节组合上限参考源 Shadow THJ2/THJ1 的正向机械范围之和。这是明确的机器人迁移策略，**不是人体临床活动范围标准**。通过角度参数化保证求解过程满足可行域，并逐阶段重新计算几何角验收。

来源与目标各取实际链段方向；Shadow 的近端弯曲按 THJ2 轴平面测量，远端按 THJ1 轴平面测量，来源中性几何偏移单独记录。来源负向弯曲若与目标非反折策略不一致，弯曲目标会投影到声明的可行范围并记录调整，原始方向/位置目标继续保留，不修改 Shadow 数据。

## 采用与回退原则

先检查原几何门槛，再检查末端弯曲、组合范围与方向/指腹代理朝向。自然性代理不通过的旧版不能以“保留旧解”继续算作通过。符合新门槛的旧解才可保留；新旧都不满足时输出待修正姿态和明确原因。

这里的检查只能确认指定几何约束，不能证明人类自然性或物理抓取稳定。代表样本先检查网球、笔、盒子，固定配置后再处理同范围批次。后续本页持续追加实际命令、试验决策和整批结果。

## 首轮实现与代表样本

独立实现 `shadow_thumb_v3.py`，复用未修改的第二版特征/几何方法。实际指节方向新增三段比较，近端/末端几何弯曲分别与来源比较；来源负向弯曲投影为 0 的记录保存在 `bend_calibration`，原始 Shadow 方向目标仍然保留。可行域用两个 [0,1] 坐标解码实际弯曲，并在第二关节的可用范围中扣除第一关节弯曲量，从而保证每一步非反折且组合不超过 130°。这个 [0,1] 是优化参数范围，不是残差范围。

两关节几何上限约 88.97° / 86.29°；组合上限采用 Shadow THJ2/THJ1 正向范围与配置 130° 的较小者。发布还检查每阶段的三段指向和参考指腹误差不超过 90°。90° 是排除反向朝向的迁移检查，不是人体关节角标准。根部两个对掌关节保持原机械范围。

网球 `case_0077__13_Precision_Sphere`、笔 `case_0158__29_Stick`、盒子 `case_0011__9_Palmar_Pinch` 首轮均通过原静态几何及新增检查。实际优化耗时约 11.6 / 30.7 / 20.1 秒，最大穿透分别约 0.70 / 0.58 / 0.62 mm。网球近端三阶段反折消除；笔抓取/收紧末端弯曲约 0.37° / 0.80°，原约 207° 的有向夹角回到不超过 180°。

约束修复不保证旧拇指代理评分继续下降：网球平均评分约 0.855→0.780，笔 0.429→0.455，盒子 0.981→1.115。后两例原目标包含负向弯曲，严格非反折策略与完全复现来源存在冲突；本版优先满足已声明的约束，保留原始来源和差异供审查，不把硬约束修复宣传成所有指标改善。

60 项回归通过，其中新增 10 项覆盖原模型随机姿态下的实际几何角/机械范围/组合约束、掌心坐标下方向的刚体不变性、模型零位校正、根部负 q 保留及不合格旧解禁止回退为通过。配置 `configs/bench2dex/shadow_thumb_v3.yaml` 已冻结：拇指阶段 55 次/全手阶段 65 次函数迭代上限，每例 220 秒预算，仅一套配置。首轮输出保存在 `output/shadow_wuji_v3/pilot_initial/`。

## 几何修复配置比较与有限追加

整批首轮中，主要新失败为阶段动作误差超过原 0.25 门槛，少量为碰撞/必要接触不满足。采用一次明确的几何修复配置比较：`shadow_thumb_v3_geometry_repair.yaml` 将整体动作残差权重 1→3、拇指动作乘数 0.3→1，其他关节先验权重 0.4→0.2，接触/碰撞残差尺度减半。机械模型、非反折/组合可行域及所有通过门槛不变。

代表失败样本中，罐子 `case_0001__1_Large_Diameter` 与清洁剂瓶 `case_0033__1_Large_Diameter` 分别约 40.3 / 27.5 秒恢复通过；碗 `case_0037__12_Precision_Disk` 约 104.4 秒后仍有碰撞/接触失败，保留待修正，不反复尝试。

决定首轮完成后，仅对首轮未通过样本追加这一套已声明配置，每例最多两次整批尝试。`tools/finalize_shadow_thumb_v3.py prepare-repair` 从首轮终态建立子集计划，继续使用同一第二版来源；`publish` 将首轮/修复结果复制到新的最终审查目录，保留两份试验、采用原因及新的结果收据，不改首轮或旧版输出。修复通过则采用；新旧都不通过仍待修正。新增 4 项发布选择边界检查通过，总计 64 项。

`tools/check_shadow_thumb_v3.py --batch output/shadow_wuji_v3/all_matched_thumb_v3` 全批完成：来源/旧矩阵逐项一致，数值/四元数/机械限位有效，359 张 PNG 校验通过；另用已有角度审计工具从实际 MuJoCo 连杆重新测量初值、初始化、提案及最终姿态。末端两个关节全部无超过 0.00001° 容差的反向弯曲，最大有向夹角约 180°、最大组合弯曲约 120.55°。所有 172 例满足新弯曲/朝向策略；其中 60 例仍不满足原静态几何门槛。

## 重力与动力学验证范围确认

用户进一步询问是否经过 MuJoCo 重力等检测。确认本批第三版及旋转导出没有进行重力保持、实际闭手、抬升或扰动验证。迁移使用 `MuJoCo_VisEnv`，其基础环境默认设置 `mjDSBL_GRAVITY`；`HandGeometry.set_pose` 写入指定姿态并调用 `mj_fwdPosition`，没有用 `mj_step` 执行真实关节控制。当前通过项仅包含机械/弯曲范围、静态穿透、表面接近以及形状/方向/阶段动作检查；接近表面不能证明接触力足以承重。结果的 `physical_passed` / `full_task_passed` 均为 null。

此前四球双侧的 8 个 MuJoCo 动力学通过样本属于另一个局部闭环批次，确实有抬升/保持/扰动及命令重放，但不能用其结论覆盖这里的 172 个 Shadow 迁移来源。后续应在开启重力、物体自由运动、实际关节控制的环境中对这些姿态重新执行闭手、抬升、保持及扰动，依据掉落/滑移/接触力和穿透等实际物理结果发布动力学标签。
