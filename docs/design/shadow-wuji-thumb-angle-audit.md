# Shadow→Wuji 拇指反折与优化函数复核

后续已按用户授权完成[第三版弯曲约束与整批复核](shadow-wuji-thumb-v3.md)。本页保留第二版问题诊断及当时的原始优化流程说明。

日期：2026-10-14。用户指出 Wuji 拇指视觉上超过人类关节阈值，要求解释 Dexonomy 的优化函数。复核范围为第二版最终选用的 172 个独立来源、每例三阶段，包含保留第一版的 40 例。

## 结论与当前缺口

当前迁移优化仅保证原始 Wuji 机械关节限位内的运动，没有人类拇指活动范围、反折禁止或关节联动的硬约束。第二版新增的位置、方向、对掌、指腹和限位余量残差仍是软目标，不能排除反折。此前“限位内”和“静态几何通过”不应被解释为自然手型验收通过。

实际存在模型正轴约定下的反向弯曲。笔的 `case_0158__29_Stick` 最终结果保留第一版：抓取时第四关节 q = −25.2128°，相邻连杆沿该关节轴法平面投影的有符号转角 = −27.4484°。若采用“伸直 180°、正向弯曲使夹角减小”的有向夹角定义，得到 207.4484°；收紧时为 208.7291°。它仍位于机器人的机械限位内，说明用户看到的反折不能用单个 q 没有超过 180° 来排除。

这不是人体关节的临床测量，机器人关节也尚未标定为人体 MCP/IP 等关节。人体拇指范围不能统一写成 0–180°，更不能直接把这个范围用作所有机器人 q 的上下界。这里确认的是原模型允许、当前迁移保留了反向弯曲自由度。

## Dexonomy 原始生成流程

原始抓取生成与本项目新增的 Shadow→Wuji 迁移是两个不同优化流程。

1. 初始物体位姿匹配：`dexonomy/op/gen_init.py` 的 `HandObjMatcher.forward` 用 Adam 优化物体旋转四元数与平移，手部模板在这一阶段不逐关节优化。实际损失为 `loss = (1000 * loss_dist + loss_normal).mean(-1).mean(-1).sum()`，其中位置误差按物体尺度还原到实际长度，法向误差为向量平方差。
2. 抓取姿态松弛：`dexonomy/op/gen_grasp.py` 的 `_single_grasp` 循环调用 `MuJoCo_OptEnv.apply_contact_forces` 和仿真步进。`dexonomy/sim/mujoco_env.py` 中施加的弹簧力为 `F = 500 * delta_normal + 100 * delta_tangent`，吸引指定手部接触点到目标物体接触点，由 MuJoCo 的运动、碰撞和关节限位求解更新手姿态。代码没有在此调用一个名为 `loss` 的手型最小化函数。固定目标时弹簧对应的点位势能可写为 `0.5 * (500 * ||delta_normal||² + 100 * ||delta_tangent||²)`，这是对力场的解释，不是代码中的额外 Adam 目标。
3. 接触筛选及收紧：`dexonomy/qp/qp_single.py` 的 `ContactQP.solve` 在摩擦等约束下求解接触力的二次规划，使总接触 wrench 与外部 wrench 的残差小。它优化接触力，不是人体自然性的关节姿态目标。求得的力随后参与 `get_squeeze_qpos` 的控制目标偏移计算。

因此原始 Shadow 看起来更合理，不能推导出更换为 Wuji 后只需套用机械限位便能保持相同自然性；两种手的关节轴、固定坐标变换和自由度都不同。

## 当前迁移优化函数

`dexonomy/integrations/bench2dex/shadow_retarget.py` 的 `budgeted_solve` 调用有上下界的 SciPy `least_squares`，目标为 `min_x 0.5 * ||r(x)||²`。第二版残差位于 `shadow_thumb_v2.py` 的 `refine_case.residual`，三阶段先优化 12 个拇指角，再优化全手及腕部共 78 个变量。

残差包含整体链形状、相对中性动作、世界指尖位置、拇指掌心位置、对掌向量、指段方向、推断的指腹法向、机械限位余量、腕部与其他手指先验、接触距离、碰撞深度及阶段变化。配置中的权重乘在残差上，再被最小二乘平方；不应把残差权重直接称为最终损失的线性系数。

唯一关节硬范围来自原始 Wuji 模型。拇指四关节范围及本批最终 q 范围如下，单位为度：

| 关节 | 原机械范围 | 最终选用 q 最小/最大 |
| --- | --- | --- |
| joint1 | 2.11 / 92.39 | 6.69 / 92.39 |
| joint2 | −9.03 / 53.35 | −9.03 / 44.34 |
| joint3 | −26.57 / 89.42 | −26.57 / 69.78 |
| joint4 | −27.67 / 88.53 | −27.67 / 88.53 |

单个 q 没有超过 180°，机械限位违例数为零。但是 q 是相对模型关节零位的旋转角，不是“伸直为 180°”的相邻指节有向夹角。j3/j4 在 q=0 时的几何有符号转角分别为 −0.4518° / −2.2356°，这是模型连杆原点偏移造成的固定差异。

## 全批测量与可复现记录

测量工具 `tools/audit_shadow_thumb_angles.py` 读取最终姿态，仅计算运动学，不修改模型、优化器或既有批次。相邻连杆原点构成的向量先投影至关节轴法平面，再通过 `atan2(axis · (incoming × outgoing), incoming · outgoing)` 计算有符号转角。正方向采用机器人原始关节轴。

工具逐例验证三阶段最终姿态有限、在机械限位内，并校验几何转角相对 q=0 的变化与实际 j3/j4 旋转一致（容差 0.0001°）。172 例全部完成。下表的 −5° 只是报告反向弯曲的诊断阈值，**不是人类活动范围标准，也不是新的通过门槛**。

| 阶段 | 最终 j3 q < −5° | 最终 j4 q < −5° | 最终 j3 几何转角 < −5° | 最终 j4 几何转角 < −5° |
| --- | ---: | ---: | ---: | ---: |
| 预抓取 | 109 | 32 | 109 | 35 |
| 抓取 | 57 | 14 | 57 | 19 |
| 收紧 | 32 | 13 | 32 | 16 |

示例：网球 `case_0077__13_Precision_Sphere` 已采用第二版，但抓取 j3 q 仍为 −20.5293°，对应有符号几何转角 −20.9811°；因此问题不限于保留旧版的样本。

输出为 `output/shadow_wuji_v2/thumb_angle_audit_2026-10-14.json`，包含每例每阶段 q、几何转角、有向夹角与选用版本。运行命令：

```bash
.viz-env/bin/python tools/audit_shadow_thumb_angles.py
```

无符号 `arccos` 夹角按定义只落在 0–180°，会丢失反折方向；本次记录的 `180 - signed_turn` 是明确约定的有向夹角，不能与无符号夹角或人体临床角度混用。

## 后续修正依据

下一次优化应先定义关节轴与屈伸方向的映射，再以 Shadow 三维指段方向/有符号弯曲为参考，设置 Wuji 机械范围与选定自然弯曲范围的交集，并增加反折、关节组合和指腹朝向的验收条件。应先在网球、笔和盒子样本上检查，不把所有负 q 一概截断为零，也不只把当前软惩罚权重调大。

新自然性门槛应参与候选采用和最终发布；若新解失败，而旧解仍有反折，则该样本应标为待修正，不能通过保留第一版把反折问题重新算作已解决。本轮只完成问题定位、解释和记录，没有运行第三版或修改原始硬件限位。
