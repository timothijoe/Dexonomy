# 当前匹配资产的 Shadow→Wuji 一代批量迁移

日期：2026-10-13。用户要求：先将已找到来源的资产全部进行迁移，缺少来源的资产以后再补；每种资产约 3–4 种握法，不做全量穷举。状态：本轮全部静态迁移与统一审查入口已完成。

## 固定本轮范围

- 使用 `asset_selection_v3/matches.json` 中已有候选的 59 个任务资产目录，不恢复缺口资产或新增来源网格。
- 每个资产优先选择 4 种现有、与物体家族相关的 Shadow 握法；若类别不足则保留实际缺口，目标至少 3 种。选择规则单独存于 `configs/bench2dex/shadow_asset_batch.yaml`。
- 目标沿用已核查的 Bench2Dex 原始 Wuji 一代右手，保留 pregrasp / grasp / squeeze 三阶段与五指语义对应；来源模型、类别、文件、索引、场景倍率和输出身份均固定。
- 重复来源姿态只做一次优化，明确记录对应的所有 Bench2Dex 目标。资产覆盖条目数与独立优化样本数分别报告。
- 源对象保持 Dexonomy 几何与已有尺度。此轮是来源手型/动作与静态接触的迁移审查，不将分类线索自动变成原 Bench2Dex 资产执行成功。

18 个仍有缺口的目录、厨房组合的部分匹配及功能设备边界继续保留在[缺口文档](bench2dex-dexonomy-asset-gaps.md)，本轮不补它们。

## 执行与统一审查

实现批量计划、有限 worker、逐样本记录、结果/来源校验续跑，以及统一离线浏览入口。每个目标按握法展示“来源 Shadow / Wuji 手型初值 / Wuji 联合优化”的三阶段图，并提供掌心对齐的纯手型对照、手型/动作误差、接触与穿透、求解停止原因和失败结果。

批量使用与首批相同的静态质量阈值与迭代次数。优化耗时受限；达到时间预算也保留有限、限位内的最佳已计算姿态用于检查，不将超时冒称为收敛。几何查询仅作位置计算，并以包围球下界排除不可能影响最小距离的碰撞对，实际接触深度继续用于防止深穿透漏报。

此轮不启动 Isaac、机械臂 IK、策略训练或新候选的抬升/保持验证。统一审查后再确定哪些迁移姿态需要修正或接入动力学。
