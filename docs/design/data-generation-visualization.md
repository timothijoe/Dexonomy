# 数据、生成与可视化边界

Dexonomy 的主数据流是：人工手型标注 → 初始化模板 → 对象匹配与位姿初始化 → 手部抓取优化 → 仿真评估 → 成功抓取与可演化模板。

对象资产、成功抓取和视觉数据属于大型外部资源；仓库只保存代码、手模型配置、小型标注与清单。项目通过 `assets/object` 访问对象数据，通过 `assets/wuji-description` 访问 Wuji2 模型。

现有 OBJ/USD 导出适合开发诊断。面向 31 类数据浏览的长期方向是独立的 GLB/JSON 静态资产与本地网页：总览页选择分类，单类页切换物体、样本及 `pregrasp/grasp/squeeze` 阶段。导出器负责正向运动学和数据抽样，浏览器不直接读取原始 NPY。
