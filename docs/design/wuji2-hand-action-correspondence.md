# Shadow / Allegro 与 Wuji2 的独立手部动作对应

## 问题与定义

现有迁移器以物体场景中的指尖世界坐标为目标；它回答“手指是否到达物体附近”。去掉物体后的比较要回答另一问题：不同尺寸、不同关节数的手是否做了相近的手指动作。直接复制关节角或比较以毫米计的指尖位置无法表达这个问题。

[`benchmarks/hand_action_correspondence_v1.json`](../../benchmarks/hand_action_correspondence_v1.json) 独立声明三种手的掌心、三根定向指根、每指指根和指尖，以及 Shadow/Allegro 到 Wuji2 的语义指映射。Shadow 对应五指；Allegro 只有四指，Wuji2 小指明确标记为未映射。源手指尖继续使用迁移结果中保存的“远端视觉网格局部 +Z 顶端 10% 均值”校准点；Wuji2 使用模型 tip site。两类点的几何定义仍有差别。

每种手在**自身**掌心建立正交坐标系：右轴沿无名指指根到食指指根，前轴沿掌心到中指指根并对右轴正交化，法轴为叉积。对于手指 `f`，记该坐标系下的指根到指尖向量为 `v_f(q)`；将手指关节置零（越界则裁到限位）得到中性向量 `v_f(0)` 和长度 `L_f = ||v_f(0)||`。记录：

- **形状** `s_f(q) = v_f(q) / L_f`：尺寸归一化后的当前指向和伸展程度。
- **动作** `a_f(q) = s_f(q) - s_f(0)`：相对于各自中性手型的变化。
- **收拢** `c_f(q) = 1 - ||v_f(q)|| / L_f`：指根到指尖距离的缩短程度；仅是运动学代理量，不等于真实接触或抓力。
- **阶段动作** `a_f(q_after) - a_f(q_before)`：比较预抓取→抓取、抓取→收紧的变化。

逐指误差是对应向量之差的欧氏范数；CSV 中为所有已映射指和三阶段的均值。它们均无量纲，**不是**指尖毫米误差，也不单独判定“同一动作”。`world_tip_error_mm` 保留物体场景下的指尖误差，用于同时观察两个目标。坐标系仅用手部解剖点，不读物体位置或接触。每例施加固定的三维刚体变换做不变性检查。

## 实现和复现

[`tools/analyze_wuji2_hand_action.py`](../../tools/analyze_wuji2_hand_action.py) 读取固定的 16 例清单与既有基线结果，计算两种误差，并可单独优化 Wuji2 的 20 个手指关节。单独拟合保留原腕位，只用动作、形状和轻度关节先验约束，遵守关节限位；它**不**把物体接触纳入损失。默认仅分析；以下命令同时生成手部动作拟合：

```bash
MUJOCO_GL=egl PYTHONPATH=. .viz-env/bin/python tools/analyze_wuji2_hand_action.py \
  --fit-hand-only --max-nfev 160
```

输出在 `output/wuji2_hand_action_v1/`：`summary.csv`、`summary.json` 和逐例 JSON。可用 `--ids sh_tripod_obj` 复现单例。源文件 SHA256、样本索引和基线结果身份均会校验。

## 当前 16 例结果

| 指标，跨 16 例均值 | 原物体场景拟合 | 独立手部动作拟合 |
| --- | ---: | ---: |
| 归一化形状误差 | 0.513 | 0.251 |
| 中性相对动作误差 | 0.530 | 0.083 |
| 收拢误差 | 0.118 | 0.097 |
| 阶段动作误差 | 0.204 | 0.043 |
| 抓取阶段世界指尖误差 | 1.73 mm | 55.45 mm |

`sh_tripod_obj` 单例的中性相对动作误差从 1.261 降为 0.462，但世界指尖均值从 1.97 mm 增为 89.18 mm。这说明两种目标确实不同：只追求手指动作会丢失原物体抓取位置。它也说明现有页面中纯手型毫米差不能直接当作动作等价性。

16 例共 48 个阶段优化中，42 个由求解器报告收敛；其余 6 个达到 160 次函数评估上限。20×48 个关节位置中有 76 个距限位小于 0.001 rad，虽无越限，仍需在后续联合目标中压低贴边比例。刚体坐标变化后的描述符最大差为 `4.64e-15 m`。

## 下一步

将动作损失作为原物体指尖、接触与碰撞目标的**辅助项**，在开发集调节权重，再在保留集检查：世界指尖误差、手物/自碰撞、关节裕量、阶段连续性，以及 MuJoCo 六方向评估。单独手部拟合的姿态尚未作为物体抓取候选进行接触优化或稳定性评估，不能称作可抓取姿态。当前指标也尚未编码关节协同、接触面的朝向与力，因此“同一动作”仍是一个可计算的运动学近似。
