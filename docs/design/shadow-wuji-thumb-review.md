# Shadow→Wuji 一代拇指姿态问题与当前优化说明

日期：2026-10-13。用户观察：整体迁移效果可接受，但 Wuji 拇指经常位置不理想、显得僵硬，而原 Shadow 拇指姿态较好。状态：本次核查现有损失和关节限位分布，未修改优化器、阈值或重跑批次。

## 当前实际优化流程

实现位于 `dexonomy/integrations/bench2dex/shadow_retarget.py`，配置为 `configs/bench2dex/shadow_retarget_batch.yaml`。

1. 建立五指语义对应与各自的解剖掌心坐标，使用中性指长归一化。
2. 每根手指使用指节原点到末端碰撞网格标记的折线，按弧长采样四个点。手型描述为这些点相对于该指指根的位置，并转换到掌心坐标；它不是采样点相对于掌心的位置。
3. 固定腕初始对齐，为每个阶段单独拟合手指关节，生成 Wuji 手型初值。
4. 联合优化 pregrasp / grasp / squeeze 的自由腕与 20 个手指关节，共 78 个变量。关节限位为硬边界，其他目标为残差加权最小二乘。

| 残差 | 当前设置 | 作用 |
| --- | --- | --- |
| 指节链手型 | 乘 2.0 | 保持按指长归一化的弯曲/指向形状 |
| 相对中性动作 | 乘 1.0 | 比较各自手模型相对中性姿态的变化 |
| 两次阶段变化 | 乘 1.5 | 保持阶段动作变化近似 |
| 指尖世界位置 | 除以 0.025 m | 接近来源末端位置 |
| 腕平移先验 | 除以 0.04 m | 控制腕位偏离 |
| 腕旋转先验 | 乘 0.2 | 控制腕方向偏离 |
| 关节初值先验 | 乘 0.03 | 避免无必要的关节偏离 |
| 必要手指与物体的最近面距离 | 除以 0.003 m | grasp 目标 +0.2 mm，squeeze 目标 -0.5 mm |
| 穿透软惩罚 | 超过 0.5 mm 的部分除以 0.001 m | 降低手物与自碰撞 |

这些是残差尺度，最小二乘对它们的平方求和，不可把毫米尺度或系数直接解释为可接受误差/实际贡献。最终筛选另外使用 2 mm 穿透/接触阈值及手型/动作/阶段变化均值阈值。

## 能确认的拇指薄弱点

- 拇指与另外四指使用同一组手型、动作和世界指尖残差，没有独立的拇指对掌约束或权重。
- 指节链描述减去了每指指根，主要描述单指弯曲和指向；未直接编码拇指相对于掌心、食指/中指的空间关系。
- 使用中心线点和末端位置，未加入经过两模型标定的指腹法向、拇指扭转或局部关节框架方向；相近中心线不保证指腹方向和视觉姿态相近。
- 接触目标是到物体任一允许碰撞面的最近距离，未限制为来源拇指的对应表面区域，也未比较来源接触点和法向。满足近接触可能仍偏离原 Shadow 的接触姿态。
- 手型与动作筛选看所有指、所有采样点的平均值，拇指的较大偏差可能被其他四指较小偏差掩盖。没有逐指最大误差或拇指单独门槛。
- 关节限位只防止越界，没有保持限位余量的惩罚；初值为零角裁到限位附近，关节先验较弱。不能保证较自然的关节协同。

原 Shadow 拇指有 THJ5–THJ1 共五个关节，Wuji 一代拇指为四个关节。关节轴和固定安装旋转不同，不能直接抄关节角，也不能仅凭各自局部轴标签判定是否同轴或不可达。这种运动学差异需要专门标定；不足以说明所观察到的不自然姿态完全由硬件决定。

## 本次限位分布核查

对 172 个独立案例的优化结果，统计拇指任意关节距离限位小于 0.001 rad 的案例数：

| 阶段 | 靠近至少一个拇指限位的案例数 |
| --- | ---: |
| 预抓取 | 143 / 172 |
| 抓取 | 122 / 172 |
| 收紧 | 102 / 172 |

抓取阶段拇指第 2 关节有 120 个案例贴近限位。原始数值记录保存在 `output/shadow_wuji_v1/all_matched_batch_v1/thumb_limit_audit.json`。靠近限位不等于越限，也不是不自然或不可达的充分证据；它说明当前目标容易把拇指解推向边界，需要单独审查。

## 建议的后续修正，尚未实现

以已有 Shadow 拇指姿态为更强的来源先验，优先增加：

1. 在标定后的掌心坐标中，约束拇指指节方向、对掌程度及拇指与食指/中指的相对关系。
2. 约束拇指指腹方向及来源接触区域，将接触优化限定为来源附近的局部适配。
3. 拇指独立权重、逐指误差输出和拇指单独验收阈值，避免用平均误差掩盖偏差。
4. 限位余量和关节协同先验，记录姿态保真与接触质量的取舍；无法兼顾的案例保留拒绝原因。

先在网球、瓶类、捏持等代表样本对比原方案与拇指约束方案，分别检查手型、指腹朝向、接触、穿透与限位，再决定是否更新整批。当前全部结果仍作为原方案基线保留，不改来源模型或限位来制造视觉相似。
