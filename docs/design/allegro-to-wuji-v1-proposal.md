# Allegro 到 Wuji 一代的手型、动作与接触联合迁移

日期：2026-10-13。状态：用户提出方向后的方案与输入核查；本次尚未实现新的联合优化器，也未产生该路线的 Wuji 一代成功样本。

后续用户改为优先采用五指 Shadow，当前主线见[Shadow→Wuji 一代联合迁移方案](shadow-to-wuji-v1-proposal.md)。以下保留为当时的 Allegro 候选方案与来源核查记录，不再代表下一版优先路线。

## 目标与判断

下一版优先采用现有 Allegro 抓取初始化 Wuji，再联合优化手型、阶段动作、真实碰撞面接触与物理稳定性。这样能为“如何握住”提供来源约束，直接回应当前球形生成中实际承力位置偏离请求类别的问题。当前 MuJoCo 抬升/保持/扰动、实际接触力审计和轨迹记录能力可复用。

目标保持相同的对应手指参与、拇指对掌关系、弯曲/张开模式、物体接触区域与阶段动作方向；不要求不同运动学模型逐关节角相等。不能在优化开始前保证所有来源抓取都可以迁移成功；超出 Wuji 限位、几何可行性或接触能力的样本必须保留失败原因。

目标模型继续使用 Bench2Dex 原始 Wuji 一代右手，使用现有原 URDF 转换模型与哈希，不将以前 Wuji2 Beta2 的结果当作本版完成证据。

## 已核查输入与历史证据

- 现有 `benchmarks/wuji2_retarget_v1.json` 中有 8 条固定 Allegro 来源样本，4 条开发、4 条保留，涵盖 DGN/Objaverse 及 `fingertip_small` / `fingertip_mid`。这些样本可作为新模型上的小型原型起点，不是总体抓取类别覆盖。
- 本次重新加载两个 DGN 开发样本，均含 `pregrasp_qpos`、`grasp_qpos`、`squeeze_qpos`，每阶段 23 维，即 7 维自由腕位姿加 16 个手指关节。
- 来源旧字段为 `hand_contact_body_names`、`hand_worldframe_contacts`、`necessary_contact_body_names`、`obj_worldframe_contacts`、`scene_cfg`。新流程需显式归一化，不能假设已经采用新字段名或新坐标约定。
- 样本提供三个阶段姿态与接触数据，不能据此声称已有完整连续动作、速度、力矩与时序真值。阶段间轨迹需要重新生成，并明确标记为合成。
- [旧 Wuji2 迁移开发基准](wuji2-benchmark.md)中 Allegro 抓取阶段平均指尖误差约 1.77 mm，但平均手物穿透约 11.66 mm，8 条均未通过六方向评估。说明只拟合指尖世界位置不足。
- [独立手部动作拟合](wuji2-hand-action-correspondence.md)在混合 16 条样本中降低了动作误差，却使抓取阶段世界指尖误差增大到约 55 mm；这些数据不能当作 Allegro 单独统计或新的稳定抓取证据。说明只拟合手型动作同样不足。

源手收紧姿态在既有重建场景中也出现明显穿透，必须重新审查尺度、接触裕量与场景约定。源成功标签不能代替当前模型与场景的验证。

## 对应与优化原则

Allegro 的拇指、食指、中指、无名指与 Wuji 对应四指建立显式语义映射，并校准两手掌心坐标、指根、各指节方向和碰撞面。结合指长归一化描述弯曲与张开程度，避免手大小差异引入假的动作误差。关节名称与轴向由模型核对，禁止直接复制 16 个关节角到 Wuji 数组。

Wuji 小指没有 Allegro 来源动作，第一版作为未映射手指，保持安全、不干涉的姿态；不计入来源动作一致性分数，也不默认参与额外承力。若之后允许小指辅助，应作为独立变体记录，不能将额外手指形成的新握法当作严格迁移成功。

对 pregrasp / grasp / squeeze 进行联合优化，而不是分别寻找三个无关的最优姿态。优化同时考虑：

1. 对应手指的完整指节方向、尺寸归一化手型、拇指对掌和指间张开关系。
2. 开手→抓取→建立握力的阶段变化，必要接触手指及物体表面的对应接触区域。
3. 所有阶段的限位、自碰撞、手物穿透、腕部偏移与阶段间连续性。

源 squeeze 可作为动作方向先验，实际握力在 Wuji 接触控制下重新求解，不继承可能穿透的源收紧角度。保持物体身份与尺度；不靠改物体大小来降低拟合误差。物理可行性检查为必要条件，手型/动作偏差也须独立设验收标准：若只有显著改变握法才能抬起，应报告动作一致性不合格。

## 最小开发闭环

先在一个 Allegro 开发样本的原物体上建立三阶段联合迁移与 MuJoCo 实际执行闭环。展示 Allegro 来源、Wuji 迁移初值、Wuji 联合优化结果的同物体/纯手型对照，逐阶段记录手型和动作偏差、实际承力手指/指节、穿透、限位、抬升、保持与扰动结果。若来源场景重建或接触本身不可信，先解决输入问题，不能静默换样本并隐藏失败。

闭环具备合理结果后，在既有固定 8 条 Allegro 来源上检查泛化，开发/保留划分不变。该集合较小，只用于开发诊断。之后才考虑将相近握法适配到 Bench2Dex 四球，跨物体传递也需独立验证。

局部物理通过与“保持来源手型/动作”分开验收，必须都满足才能标记该路线的成功迁移。Allegro 的两个指尖模板不覆盖 Dexonomy 全部 31 类；更广类别可在迁移机制成熟后引入五指 Shadow 来源。
