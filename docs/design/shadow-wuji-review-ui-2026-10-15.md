审查重点是原 Shadow 的抓取意图是否被最终 Wuji 保留。V2 保留为优化初值、比较基线及合格候选，无需始终占据主界面的一列。

- 总览和独立旋转页默认两列：原 Shadow / 最终选用 Wuji。预抓取、抓取、收紧共六格。
- 展开“显示历史对照（V2）”后增加中间历史列，三阶段恢复九格；收起后恢复两列。
- 最终结果沿用 V2 时直接显示在最终列，注明来源与当前静态约束；待修正结果明确标为提案，动力学状态单独显示。
- 总览保留资产、状态、结果来源和文字筛选，以及带物体/纯手型、放大和历史文件入口。

## 三轴控件入口修正

用户反馈没有看到 Roll、Pitch、Yaw 按钮。复查发现当时总览及放大窗口仍只有固定画面，三轴控件只在独立旋转页，因此仅验证独立页不能覆盖直接打开总览的使用路径。

现总览工具栏和放大窗口顶部均直接提供 Yaw / Pitch / Roll 按钮及滑条，同步更新可见握法的三阶段画面。Yaw 为十二档、每档 30°；Pitch 为 −65°、−45°、−25°、−5°、15°；Roll 为十二档、每档 30°。Yaw/Pitch 读取已有 MuJoCo 多视角帧，Roll 是画面旋转。独立旋转页继续支持拖动、重置及三轴操作，无需 WebGL。

总览复用已有 `rotation/frames/`，不重新优化姿态或导出帧。展开历史、切换显示模式时保留当前角度；总览和放大窗口的角度保持一致。

## 查看与复现

直接打开 `output/shadow_wuji_v3/all_matched_thumb_v3_final/index.html`，筛选栏下方即为三轴控件；独立页为同目录下的 `rotation/index.html`。

已有数据只刷新界面时运行：

```bash
.viz-env/bin/python tools/review_shadow_thumb_v3.py
.viz-env/bin/python tools/review_shadow_thumb_v3_rotation.py
```

页面检查入口：

```bash
.viz-env/bin/python tools/check_shadow_thumb_v3_browser.py
.viz-env/bin/python tools/check_shadow_thumb_v3_rotation_browser.py
```

完整离线包 `review_v3_rotatable_bundle.zip` 包含旋转帧，支持总览和放大窗口三轴操作。固定图包 `review_v3_bundle.zip` 不包含这些帧，会明确提示使用完整旋转包，不显示无效的旋转入口。两份包及各自 README 已刷新，内容及 CRC 校验通过。
