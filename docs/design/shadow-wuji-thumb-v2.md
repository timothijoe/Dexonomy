# Shadow→Wuji 一代拇指第二版优化

2026-10-14 复核：第二版仍有模型允许的拇指反向弯曲，不能以机械限位内或静态通过认定自然性问题已解决。详见 [拇指反折与优化函数复核](shadow-wuji-thumb-angle-audit.md)。该复核没有覆盖或修改本页所述第二版输出。

后续已完成[第三版非反折可行域及整批对照](shadow-wuji-thumb-v3.md)，原第二版结果继续保留作基线。

日期：2026-10-13。用户授权：根据已优化结果继续，或重新初始化，由开发者权衡后实施第二版。当前状态：同范围整批第二版、成对数值/来源校验和统一审查入口已完成。

## 本轮选择

优先从第一版优化姿态继续，以保留已有整体手型与接触；原 Shadow 三阶段姿态继续作为目标，第一版不会成为拇指自然性的真值。另以第一版的手型拟合初值作为重新初始化对照。来源资产、类别、索引、尺度和原始模型限位保持一致，第一版结果只读保留。

目标为此前相同的 59 个资产 / 236 个覆盖条目 / 172 个独立来源，Wuji 一代右手。没有补缺口，也不增加新资产。所有结果仍是静态姿态与几何检查，无真实控制或动力学成功标签。

## 新约束与几何标定

第二版在 `shadow_thumb_v2.py` 中独立实现，复用第一版的模型/运动学与几何接口，避免改动已完成第一版的代码身份与结果。

- 拇指相对于掌心的四个链采样点，按中性拇指长归一化；补足第一版只比较指根相对形状的缺口。
- 拇指与食指/中指指尖的相对向量，以及拇指各段方向，避免平均误差掩盖拇指偏差。
- 来源指腹参考来自 Shadow 原始 `13_Precision_Sphere` 人工标注的 `rh_thdistal` 接触法向。标注点到当前碰撞网格距离实测约 0.0106 mm，符合几何校验。
- Wuji 指腹参考是在中性姿态中、朝向食指/中指的末端碰撞网格面；它是根据几何与解剖关系推断的参考面，不宣称实际传感器区域或硬件指腹标定完成。
- 拇指实际朝向和两次阶段变化单独纳入损失；源拇指远端近接触且为必要手指时，以来源物体表面位置约束目标参考接触区域。
- 拇指限位余量增加软惩罚，硬限位不变；其他四指和腕部受到相对于第一版的保守先验，避免为了拇指改善而大幅改动整体握法。

执行分两阶段：先只优化三阶段拇指的 12 个角度，再允许三阶段全手/腕的 78 个变量作有限修正。数值预算固定，停止原因单独保存。

## 选择与保留机制

第二版候选必须通过与第一版相同的几何、手型、动作与接触筛选。拇指评分单独由掌心相对位置、对掌向量、指段方向、参考指腹朝向构成，不能仅以关节远离限位作为改善。

当第一版已通过而第二版破坏原几何通过状态时保留第一版。第二版需要拇指综合误差实际改善，并限制任何单项指标明显倒退；否则仍保留第一版并记录原因。第二版提案与最终选用姿态都保存；保留第一版时另输出未采用提案图片，避免隐藏失败尝试。

## 代表样本开发记录

网球指尖抓取首个测试：原方案拇指平均综合误差约 0.993，继续优化约 0.885；从手型初值重新初始化约 0.885，两者都通过原静态几何筛选。仅增加较弱限位余量惩罚仍使拇指第二关节贴近下限。加强余量惩罚后，该样本第二关节三个阶段均离开原下限，但综合误差改善幅度较小，约为 0.922。上述是开发比较，不作为全批改善结论。

清洁剂瓶大直径抓取继续优化的首个测试也通过原几何筛选，拇指评分从约 1.169 降为约 1.034。正在进一步比较更强的方向、对掌和余量约束，再冻结配置执行同范围批次。所有试验目录保留在 `output/shadow_wuji_v2/`。

进一步比较：加强方向/掌心位置后，网球、清洁剂瓶、书写握法的拇指综合误差分别从约 0.993 / 1.169 / 0.951 降到 0.838 / 0.981 / 0.785，均通过原检查；但前两例第二关节仍多次贴边。增加余量和对掌权重后，网球/书写握法第二关节离开边界，清洁剂瓶却触发原动作偏差门槛，因此应保留旧解或尝试保守配置，不能以释放限位为由放宽通过标准。

## 最终开发决策与批次

采用第一版优化结果作为起点。网球的重新初始化与继续优化结果接近，没有支持整批重新初始化的明显收益。主要配置优先改善对掌、位置、方向并释放限位；若提案不适合，最多再尝试一次较保守的同类配置。两次都按相同原质量门槛和拇指逐项/逐阶段保护检查，最终仍可保留第一版。所有主提案、保守提案及选用版本分别保存，不无限重试。

固定配置：`configs/bench2dex/shadow_thumb_v2.yaml` 与 `shadow_thumb_v2_conservative.yaml`。独立批量实现为 `thumb_v2_batch.py`，入口 `tools/batch_shadow_thumb_v2.py`；来源为已完成第一版 `all_matched_batch_v1/`，输出 `output/shadow_wuji_v2/all_matched_thumb_v2/`，59 个资产、236 个覆盖条目、172 个独立来源，缺口不变。

第二版的九格图现在表示“Shadow 来源 / 第一版优化后 / 本次选用结果”，每行仍为预抓取、抓取、收紧。选用旧解时第三行明确标为保留第一版，另提供未采用提案图。统一入口 `index.html` 可按资产、静态状态及选用版本过滤，并比较拇指综合误差和几何推断的指腹朝向误差。

已新增拇指特征对刚体坐标变化的不变性、几何回退、单项/逐阶段误差退化保护与保守提案保留/发布检查，目前总计 50 项回归通过。初步统一入口已在浏览器检查 236 张卡片、版本筛选、资产筛选与图片切换，未发现 JavaScript 错误。整批最终结果将在全部 172 个来源完成后追加。

全部 172 个独立来源已完成，覆盖原 59 个资产的 236 个条目，使用相同第一版来源、类别、索引、场景倍率与原始 Wuji 一代右手。实际执行主配置 172 次，另有 50 次保守配置尝试，总计 222 次有限配置尝试，不把保守尝试隐藏在独立案例数内。

最终选用结果有 153 个独立来源通过原静态筛选、19 个仍需调整，覆盖条目分别为 207 / 29。第一版对应为 151 / 21；新增恢复 2 个静态候选，原先通过的案例没有退化。保留旧解不代表第二版优化未运行：主/保守提案与选择原因都已保存。

## 输出与验证

目录为 `output/shadow_wuji_v2/all_matched_thumb_v2/`。`index.html` 是统一查看入口，`review_v2_bundle.zip` 是完整离线审查包，解压后打开页面。

- `postures.npz` 保存 Source / V1 / V2 初始化 / V2 提案 / 最终选用；保留第一版时选用数组与原数组严格一致。
- `result.json` 保存专门拇指指标、原静态判据、主/保守配置尝试、几何代理标定与选用原因。
- `primary_trial/`、`fallback_trial/` 和 `proposal/` 保留未采用结果及图片；最终图片明确 Source / V1 / 选用结果。
- `paired_check.json` 包含独立案例与覆盖条目的成对统计，以及输入/输出身份、限位、四元数、保留/质量退化检查。

50 项回归检查通过。整批校验续跑通过，没有重新优化已完成案例。172 个案例均有有限、限位内、单位四元数的三阶段姿态；全部第一版来源与输出身份验证通过，原通过案例退化数为 0。684 张图片（包含提案/试验副本）经过文件校验。浏览器逐一切换全部 59 个资产，在两种模式下解码每个资产的四种图；采用第二版/保留旧版筛选分别为 185 / 51 张卡片，图片放大、Esc 与文字筛选正常，无 JavaScript 错误。

第一版输出未覆盖，原模型硬限位未变，缺口资产未补。该版本交付的是可逐项审查的拇指改进，后续仍需用户视觉检查，不能以代理误差下降替代自然性或真实稳定握持验收。

## 配置和审查约定

主配置的拇指掌心/对掌/指段残差权重均为 4，参考指腹方向权重为 3；拇指软余量目标 0.08 rad、权重 3。保守配置保持掌心/指段权重 4、对掌权重 2、方向权重 3，将余量权重降低至 1.2。余量是软目标，不改变硬限位，不通过强制远离边界制造姿态改善结论。

原质量门槛保持：最大穿透 2 mm、必要接触距离 2 mm，整体手型/相对中性动作均值 0.25，阶段变化均值 0.15。采用新解还需拇指综合误差至少下降 2%，各专门指标平均值不能明显退化，三个阶段的拇指综合误差分别受到退化保护。每案例最多两次已声明的配置尝试，独立来源数、实际尝试数及目标覆盖条目分别统计。

第一版同模型、同来源的姿态为成对基线，来源和旧结果校验后只读。第二版指标检查工具 `tools/check_shadow_thumb_v2.py` 会验证所有结果收据、有限值/四元数/限位，检查旧解保留时数组与第一版严格相等、已通过旧质量的案例不退化，并输出拇指评分、参考指腹角度和贴近限位数量的成对统计。
