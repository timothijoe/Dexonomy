## 当前版本快照

目标为 Bench2Dex 原始 Wuji 一代右手，来源为 Shadow。当前 59 个资产、每资产四份握法对照、236 个覆盖条目、172 个独立来源已完成三阶段迁移。最终 136 个第三版通过、15 个满足新检查的第二版保留、21 个待修正，即 151 个独立静态候选。全部选用姿态的末端两个关节通过非反折检查。

实际验证：64 项回归通过；全部来源/旧数组/四元数/机械限位/实际连杆角度核查通过；599 张图片与全部 59 个资产的两模式浏览器检查通过。两个第二版旧几何候选因动作误差转为待修正，原几何门槛未放宽。完整结果与限制见 [第三版记录](shadow-wuji-thumb-v3.md)。

当前入口为 `output/shadow_wuji_v3/all_matched_thumb_v3_final/index.html`，离线包 `review_v3_bundle.zip`。当前页面支持筛选、带物体/纯手型、图片放大及逐阶段角度对照，**仍是固定视角图片，没有旋转控件**。实际握持和动力学验证尚未完成。

Git 提交保存实现代码、配置、来源清单、测试、需求和开发文档。生成的姿态、图片、离线包与外部模型/数据遵循既有忽略规则，不作为 Git 中的数据本体提交；复现入口及数据路径由清单与教程说明。

## 已查看的旧实现

- `tools/export_wuji2_comparison.py`：MuJoCo 预渲染角度网格，水平从 135° 开始、每 30° 一档、共 12 档；俯仰为 −65°、−45°、−25°、−5°、15° 五档。
- `tools/wuji2_comparison.html` / `.js`：水平、俯仰、滚转各有滑条及前后按钮，图片拖动同步调整水平/俯仰。滚转为画面平面旋转，30° 一档，共 12 档。
- `docs/design/wuji2-comparison.md` 和 `tutorials/visualize_wuji2_comparison.md`：记录了不依赖 WebGL 的离线多视角方式及旧版实际验证。

旧实现里的手模型是 Wuji2；后续复用相机控制与离线网格思路，姿态和模型必须继续使用本次 Wuji 一代第三版。

1. 为第三版选用姿态增加同样的 12×5 离线观察方向及 30° 滚转控件；水平/俯仰使用实际新渲染，滚转在画面平面进行。
2. 比较 Shadow、第二版最终选用、第三版最终选用。支持预抓取/抓取/收紧，以及带物体和掌心对齐纯手型，两种手模型保留原始尺寸。
3. 同一组角度控件同步各比较格，提供滑条、按钮、画面拖动和重置。保留已有固定九格图及角度报告作为审查依据。
