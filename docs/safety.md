# 安全与副作用边界

## 文件与数据

- `output*`、对象数据、模型权重、日志和调试产物不进入 Git。
- 删除、覆盖或移动外部数据前必须确认目标和恢复方式。
- 不把另一台机器的虚拟环境复制进仓库。
- NPY 数据使用 `allow_pickle=True` 读取，只应加载可信来源文件。

## 计算资源

- `init` 可占用指定 GPU；运行前检查 `init_gpu`。
- 抓取和评估默认使用多进程，`n_worker` 默认值较高；首次验证应设为 1。
- `dexsyn` 和 `dexsyn_admm` 会反复调用阶段命令，日志结束条件未满足时可能长期运行。
- GUI 模式要求显示环境；headless 渲染通常需要 `MUJOCO_GL=egl`。

## 外部系统

- BODex 只用于轨迹生成，未安装时保持 `skip_traj=True`。
- Wuji2 当前只有模型资源和运动学映射交接样例，没有物理抓取或真机验收。
- 未经明确授权，不连接真机、外部服务或执行产生外部副作用的操作。

## 许可

Dexonomy 数据按项目声明采用 CC BY-NC 4.0；Wuji Hand 2 模型采用 MIT。对外分发和商业用途必须分别遵守来源许可。
