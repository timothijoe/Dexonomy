# Shadow 31 类抓取数据

## 布局

数据根目录为 `Dexonomy_GRASP_shadow/succ_collect/<抓取类型>/<对象>/<场景>/<尺度>.npy`。当前共有 31 个类型目录，约 150 万个 NPY 文件。

## 分类

存在编号 1–18、20、22–33。原始 Shadow 标注还包含 `19_Distal` 和 `21_Tripod_Variation`，但成功抓取数据没有这两个目录。类型名保持上游拼写，包括 `18_Extensior_Type`。

## 文件语义

一个 NPY 文件对应一个对象场景和尺度，其中可包含多条成功抓取。抽样文件字段为：

- `scene_path`：项目相对的场景配置路径。
- `scene_scale`：每条成功抓取对应的物体尺度倍率。图鉴导出时将其乘到活动刚体的场景配置 `scale` 上；忽略倍率会使部分姿态看起来没有接触。
- `pregrasp_qpos`、`grasp_qpos`、`squeeze_qpos`：形状 `[N, 29]`。

29 维姿态由 7 维自由手腕位姿和 22 个 Shadow Hand 关节组成。场景配置进一步指向对象视觉网格、碰撞模型、尺度和初始位姿。

## 可视化抽样建议

不要直接取目录中的第一个文件作为类别代表。应先按对象和尺度分层，再在关节和手腕姿态空间选择中心与边界样本。总览页每类使用一个中心样本，单类页保留多个物体与多个姿态。
