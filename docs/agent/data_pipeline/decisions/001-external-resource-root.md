# 001：大型资源使用仓库外根目录

- 状态：accepted
- 日期：2026-09-25

## 背景

Dexonomy 对象、视觉、抓取和权重数据解压后约 47 GB，并包含大量生成结果和小文件，不适合进入代码仓库。代码默认通过 `assets/object` 访问对象资源。

## 决定

大型资源放在仓库外的正式根目录中，通过 `assets/object` 等被 Git 忽略的入口链接接入。当前机器根目录为 `/data/robotic_data/ztDexonomy`，但代码和配置不得依赖该绝对路径。

## 影响

仓库保持轻量，数据可单独校验和恢复。新机器需要先安装资源并创建入口链接；教程和 manifest 必须记录恢复方法。
