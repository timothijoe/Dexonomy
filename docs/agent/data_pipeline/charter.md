# 数据与资源长期章程

## 目标

为生成、评估和可视化提供可追踪、可恢复、不会污染 Git 的对象数据、抓取结果、视觉数据、模型权重和机器人模型。

## 稳定原则

- 大型资源保存在仓库外，由项目内固定入口链接访问。
- 每项外部资源记录来源、版本、许可、校验值、目标布局和恢复方法。
- 归档校验失败时不解压、不使用。
- 不把密钥、私有 SDK、受限数据或虚拟环境写入 Git。
- 数据格式演进保留明确兼容层，不在读取时静默猜测含义。

## 完成标准

资源安装应至少验证：校验值、目标目录、关键文件存在、项目入口可解析、Git 忽略生效、许可记录存在。

详细当前事实见[外部资源布局](evolution/external-resource-layout.md)与[Shadow 31 类数据](evolution/shadow-grasp-dataset.md)。
