# ADMM 抓取优化

## 当前实现

`op=grasp_admm` 在原始 MuJoCo 手姿态优化基础上加入三步循环：

1. 在物体三角网格表面更新对象接触点，并以可微 QP 的残余作为抓取质量目标。
2. 将目标接触投影到手部碰撞网格，通过 MuJoCo 接触力更新手部姿态。
3. 更新对象与手接触点的差异及对偶变量。

QP 实现位于 `dexonomy/qp/qp_single.py` 的 `ContactQPTorch`。对象点更新使用 `rho_admm`、`lr_obj`、`step_obj`；手部更新使用 `step_hand` 和仿真 `substep`。

## 设备与并行

默认配置使用 CPU。CUDA 路径会按 GPU 和每 GPU 进程数生成 worker 槽位，但当前尚未在本机验证。

## 失败语义

可微 QP 返回空值或抛出异常时，样本会回退到固定 20 步的原始接触力优化。最终仍需通过关节限制、碰撞、接触身体和 QP 误差过滤。分析 ADMM 效果时应记录回退比例，目前输出没有单独持久化该标志。

## 当前验证

实现和配置已静态检查；没有本机数值复现、性能数据或成功率统计。上游说明中的论文结果不能作为当前环境验收。
