# 生成流水线

## 当前入口

- `dexrun op=tmpl`：把 `raw_anno/*.yaml` 转为初始模板 NPY。
- `dexrun op=init`：固定手模板，采样并优化对象相对位姿。
- `dexrun op=grasp`：固定物体，通过 MuJoCo 接触力调整手腕与关节。
- `dexrun op=eval`：执行 force-closure 或运动任务评估。
- `dexsyn`：并行启动初始化、抓取、评估和可选轨迹阶段。

## 数据流

模板转换输出包含抓取姿态、接触点、接触身体及必要接触组。初始化输出增加对象接触点、场景路径、外力中心和外力矩。抓取优化增加最终 `grasp_qpos`、`squeeze_qpos`、`pregrasp_qpos` 和实际接触信息。评估成功后，在成功目录创建链接，并可把抓取结果加入演化模板库。

## 模板更新

`tmpl_upd_mode` 支持：

- `orig`：保留模板局部接触。
- `real`：使用仿真实际接触。
- `hybrid`：在距离和法向接近时用实际接触替换模板接触。
- `disabled`：不进入后续模板演化。

## 调度语义

`dexsyn` 为每个模板分配一个初始化 GPU，抓取和评估同时轮询上游目录。完成条件来自日志中的固定文本，而不是进程间状态协议。修改日志文案时必须同步检查调度器。
