# 2026-09-26：浏览器 3D 诊断与下载入口

## 目标

回应用户“静态画面能看，但 3D 似乎不能看”的反馈，区分模型传输和浏览器渲染失败，并保留查看真实 3D 文件的途径。

## 实际完成

- 手动切换 3D 时检查 WebGL 上下文能否创建。
- 在模型 `load` 事件后用 `model-viewer` 的画面截图检查蓝色手部是否进入渲染帧；为快速切换时的首帧延迟加入重试。
- WebGL 不可用、组件加载失败、渲染帧空白或上下文丢失时，保留同阶段 PNG 并显示具体提示。
- 增加“下载当前 GLB”入口，随类别、样本、阶段切换更新。

## 验证与限制

本机 Chrome 中正常 3D 可以通过渲染检查；禁用 WebGL 和模拟空白渲染帧均触发静态兜底。几个不同类别和阶段在快速切换后仍可进入 3D。服务器日志显示相关 GLB 请求成功，但这只能说明文件传输，不能证明用户浏览器完成绘制。用户侧新版本尚未复测；实际原因仍需根据用户浏览器及界面提示确认。
