# 2026-09-26：Shadow 图鉴静态优先预览

## 目标

让用户在浏览器中稳定看到 Shadow Hand 与物体的抓取关系，并保留交互 3D 入口。

## 实际完成

- 导出器为三种类型、每类三个样本分别生成 `pregrasp`、`grasp`、`squeeze` 的 GLB 和真实场景 PNG，总计 27 个 GLB、27 张 PNG。
- 将汇总抓取数据的逐条 `scene_scale` 乘到活动刚体的场景尺度。先前忽略该倍率时，部分画面显示手物明显分离。
- 页面加入本地 `model-viewer`、阶段与样本切换及同阶段图片兜底。最初自动切入 3D，用户反馈画面闪现后消失；随后改为静态首屏，点击时才导入 3D 组件。
- 用户反馈“现在至少可以看了”，确认静态画面在其访问路径上可见。

## 验证证据

- 9 条索引记录引用的全部 27 个 GLB、27 张 PNG 均存在，三阶段图片内容不同。
- 本机 Chrome headless 截图可见手和物体；浏览器脚本在打开后第 1 秒和第 24 秒均观察到静态图片可见、3D 组件未加载。
- 本机检查了手动进入 3D、返回静态、阻断组件加载后的静态兜底，以及类别、样本和阶段切换。
- Python 静态编译、JavaScript 语法检查、网页模板与输出副本一致性检查通过。

## 当时限制与后续影响

用户只确认静态画面可见，尚未确认其浏览器中的 3D 交互。当前样本按对象目录抽样，并非质量排序的类别代表；可视化不能代替物理抓取评估。下一步先验证用户侧 3D，再改进抽样和扩展类别。当前完整事实维护在[抓取图鉴纪传体](../evolution/grasp-taxonomy-visualization.md)。
