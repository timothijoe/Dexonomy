# 2026-09-29：无 WebGL 环绕视角回退

用户浏览器点击 3D 后明确提示无法创建 WebGL 上下文。实时 GLB 查看器依赖 WebGL，因此改用 MuJoCo 为每个样本、每个抓取阶段预渲染 12 个水平方向的环绕视角。首帧复用原 PNG，其余 11 帧保存为 WebP。网页在 WebGL 不可用或模型画面渲染失败时自动进入多视角模式，可拖动图片或点击箭头切换角度，并明确标注这是预渲染画面。GLB 下载仍可使用。

本机检查：9 条记录、27 个阶段、324 个视角引用全部存在；抽查一组 12 帧内容均不同，目视检查背面视角中手与物体可见。禁用 WebGL 的 Chrome 中验证了自动回退、换角度、阶段切换和图片加载；正常 Chrome 中实时 GLB 加载与显示仍成功。用户浏览器中的新模式尚待验收。
