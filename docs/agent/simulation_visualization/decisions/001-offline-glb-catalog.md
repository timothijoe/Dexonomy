# 001：图鉴采用离线 GLB/JSON 导出

- 状态：accepted
- 日期：2026-09-25

## 背景

原始数据约有 150 万个 NPY 文件，使用 pickle 对象格式，并依赖 MuJoCo 模型完成正向运动学。现有 USD/OBJ 工具缺少适合分类浏览的导航和元数据。

## 决定

31 类图鉴使用离线导出器生成少量代表性 GLB 和 JSON 索引，浏览器只加载导出资产。OBJ/USD 继续保留为诊断和研究格式。

## 影响

浏览端无需 Python、MuJoCo 或读取 NPY，便于本地查看和分享。代价是需要维护可复现抽样和导出流程，并在源数据变化后重新生成资产。
