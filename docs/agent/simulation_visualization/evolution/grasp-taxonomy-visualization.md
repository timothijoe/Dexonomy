# 31 类抓取图鉴

## 目标产品

图鉴分三层：

1. 31 类总览页：分类名称、代表姿态、代表物体和样本数量。
2. 单类浏览页：切换物体、尺度、样本及 `pregrasp/grasp/squeeze`。
3. 类内多样性页：展示不同物体、尺度、腕姿和关节构型的代表样本。

## 技术边界

离线导出器读取可信 NPY 和场景配置，使用 MuJoCo 做正向运动学，输出 GLB、PNG、预渲染视角 WebP 与 JSON 索引。网页仅加载导出资产，支持阶段播放、样本切换、源数据定位，以及手动进入实时 3D 后的旋转和缩放。浏览器不能创建 WebGL 时进入预渲染多视角模式。部件显隐尚未实现。现有 OBJ/USD 工具继续用于调试和研究导出。

## 抽样原则

- 先按对象和尺度分层。
- 在手腕与关节空间选取中心样本作为类别封面。
- 选择多个距离较远的代表样本展示类内多样性。
- 每个导出样本保留原始 NPY 路径和数组索引。

## 当前进度

已确认 31 类目录、每类文件数、样本字段、三阶段姿态、对象网格与尺度解析路径，并恢复 Shadow 网格子模块。

首个原型已经完成：

- 类型：`1_Large_Diameter`、`14_Tripod`、`24_Tip_Pinch`。
- 每类选择三个不同对象，每个文件使用中间抓取索引。
- 每个样本导出 `pregrasp/grasp/squeeze` 三个 GLB 和三张由 MuJoCo 真实场景渲染的 PNG。
- 每个阶段另有 12 个水平角度 × 5 个俯仰角度的相机视角；基准视角复用 PNG，其他视角为 WebP。27 个阶段共 1620 个视角引用。
- 共 9 条记录、27 个 GLB 和 27 张 PNG。
- JSON 中保留分类、源 NPY、数组索引、场景路径、逐抓取物体尺度倍率和阶段文件。
- 抽样 GLB 重新加载成功，每个包含手和物体两组几何。

导出器为 `tools/export_taxonomy_preview.py`，网页模板和交互代码分别为 `tools/taxonomy_preview.html` 与 `tools/taxonomy_preview.js`，生成目录为 `output/taxonomy_preview`。网页默认显示静态 PNG，只有用户点击切换时才载入交互 3D；WebGL 不可用、加载失败或渲染帧空白时进入同阶段预渲染多视角，若视角文件缺失则保留 PNG。组件打包为本地文件，不依赖 CDN。

多视角模式有三组左右箭头：水平环绕 12 档、上下俯仰 5 档、画面滚转 30° 一档。水平和俯仰由不同的 MuJoCo 相机画面提供，滚转由浏览器旋转当前图片，故不会产生新的遮挡信息。拖动同时控制水平与俯仰；切换阶段或样本保留视角，重置按钮恢复基准角度。它提供离散视角观察，不等同于连续的实时 3D。

## 原型验收

首版 3 类 × 3 样本的资产生成与结构验证已经完成。2026-09-25 使用本地 HTTP 服务和 Chrome headless 实际加载旧网页并截图；2026-09-26 更新后又在本机浏览器检查了静态首屏可见、图片自然宽度、类别/样本/阶段切换、交互 3D 加载和模拟 3D 错误后的兜底。新 PNG 来自实际三阶段场景渲染，不再使用旧截图裁剪物。检查九张抓取图时发现若忽略 `scene_scale`，有些物体明显远离手；几何距离复核后导出器已将逐抓取倍率应用到活动物体。

用户曾在自动切入 3D 时看到画面闪现后消失；取消自动切换后，用户确认静态画面可以看到，并明确报告浏览器无法创建 WebGL 上下文。2026-09-29 已新增无 WebGL 多视角回退和三组方向控制；本机核对 1620 个视角引用全部存在，在禁用 WebGL 的 Chrome 中逐组验证按钮、图片切换、阶段切换保留视角并截图检查布局，在正常 Chrome 中再次验证实时 3D。用户对三方向版本给予正面反馈，但没有记录逐项用户侧验收。当前样本按对象名确定性抽取，每个文件取中间索引，尚未实现上文规划的质量和多样性抽样。批量扩展到 31 类前仍需评估代表样本质量、加载性能和不同浏览器的 3D 交互。
