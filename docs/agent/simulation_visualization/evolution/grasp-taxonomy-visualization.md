# 31 类抓取图鉴

## 目标产品

图鉴分三层：

1. 31 类总览页：分类名称、代表姿态、代表物体和样本数量。
2. 单类浏览页：切换物体、尺度、样本及 `pregrasp/grasp/squeeze`。
3. 类内多样性页：展示不同物体、尺度、腕姿和关节构型的代表样本。

## 技术边界

离线导出器读取可信 NPY 和场景配置，使用 MuJoCo 做正向运动学，输出 GLB、PNG 与 JSON 索引。网页仅加载导出资产，支持阶段播放、样本切换、源数据定位，以及手动进入 3D 后的旋转和缩放。部件显隐尚未实现。现有 OBJ/USD 工具继续用于调试和研究导出。

## 抽样原则

- 先按对象和尺度分层。
- 在手腕与关节空间选取中心样本作为类别封面。
- 选择多个距离较远的代表样本展示类内多样性。
- 每个导出样本保留原始 NPY 路径和数组索引。

## 当前进度

已确认 31 类目录、每类文件数、样本字段、三阶段姿态、对象网格与尺度解析路径，并恢复 Shadow 网格子模块。

首个原型已经完成：

- 类型：`1_Large_Diameter`、`14_Tripod`、`24_Tip_Pinch`。
- 每类选择三个不同对象，每个文件使用中间抓取索引。
- 每个样本导出 `pregrasp/grasp/squeeze` 三个 GLB 和三张由 MuJoCo 真实场景渲染的 PNG。
- 共 9 条记录、27 个 GLB 和 27 张 PNG。
- JSON 中保留分类、源 NPY、数组索引、场景路径、逐抓取物体尺度倍率和阶段文件。
- 抽样 GLB 重新加载成功，每个包含手和物体两组几何。

导出器为 `tools/export_taxonomy_preview.py`，网页模板和交互代码分别为 `tools/taxonomy_preview.html` 与 `tools/taxonomy_preview.js`，生成目录为 `output/taxonomy_preview`。网页默认显示静态 PNG，只有用户点击切换时才载入交互 3D；3D 失败或超时后保留同阶段 PNG。组件打包为本地文件，不依赖 CDN。

## 原型验收

首版 3 类 × 3 样本的资产生成与结构验证已经完成。2026-09-25 使用本地 HTTP 服务和 Chrome headless 实际加载旧网页并截图；2026-09-26 更新后又在本机浏览器检查了静态首屏可见、图片自然宽度、类别/样本/阶段切换、交互 3D 加载和模拟 3D 错误后的兜底。新 PNG 来自实际三阶段场景渲染，不再使用旧截图裁剪物。检查九张抓取图时发现若忽略 `scene_scale`，有些物体明显远离手；几何距离复核后导出器已将逐抓取倍率应用到活动物体。

用户曾在自动切入 3D 时看到画面闪现后消失；取消自动切换后，用户确认静态画面可以看到。本机浏览器已检查手动进入 3D、返回静态和组件加载失败兜底；用户浏览器的 3D 交互尚未验收。当前样本按对象名确定性抽取，每个文件取中间索引，尚未实现上文规划的质量和多样性抽样。批量扩展到 31 类前仍需评估代表样本质量、加载性能和不同浏览器的 3D 交互。
