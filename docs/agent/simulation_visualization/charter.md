# 仿真与可视化长期章程

## 目标

提供可重复的手部正向运动学、接触提取、抓取物理评估和诊断可视化，并为大规模数据浏览输出轻量资产。

## 稳定原则

- 仿真成功与视觉上看似合理必须分开报告。
- 视觉网格、碰撞网格和物理接触应可分别显示。
- headless、GUI 和离线导出是不同验证等级。
- 浏览器不直接加载可信边界不明确的 NPY pickle；先导出 GLB/JSON。
- 数据集浏览应采用可复现抽样，并保留源文件和样本索引。

## 完成标准

可视化能力变更至少应验证一个真实手物场景、三个抓取阶段、物体尺度、相机范围和导出文件可重新打开。物理评估变更还需独立运行成功与失败样本。

详细当前事实见[MuJoCo 环境](evolution/mujoco-environment.md)和[31 类图鉴](evolution/grasp-taxonomy-visualization.md)。
