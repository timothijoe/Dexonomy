# 仿真与可视化当前总览

当前原型的用户侧显示问题、未完成项和后续顺序见[项目交接文档](../../../HANDOFF.md)。

## 当前能力

- [MuJoCo 环境](evolution/mujoco-environment.md)：代码支持模型装配、运动学、接触、优化和评估。
- [31 类图鉴](evolution/grasp-taxonomy-visualization.md)：3 类 × 3 样本原型已有 27 个 GLB、27 张三阶段图片，以及每阶段 12 × 5 个水平/俯仰视角；本机浏览器已检查实时 3D 和无 WebGL 回退。
- [Wuji2 三阶段对照](../../design/wuji2-comparison.md)：16 条 Shadow/Allegro 样本的手物与掌心对齐纯手型图片、GLB 和静态网页；本机浏览器已检查样本、阶段、视角切换。
- [Wuji2 双版本](evolution/wuji2-dual-viewers.md)：手物交互拟合与独立纯手型动作拟合分别导出页面；新纯手型页有 16 例、三阶段、双手同步离线旋转与仅含手的 GLB。两个版本的姿态目标不同，均不构成稳定抓取。

## 当前证据

- `vis_3d` 和 `vis_usd` 的代码路径已阅读。
- MuJoCo Menagerie 子模块已于 2026-09-25 恢复到固定提交，Shadow 网格存在。
- 项目内 `.viz-env` 已安装最小渲染依赖，真实 Shadow 场景加载成功。
- 已生成 27 个 GLB、27 张 PNG、一个 JSON 索引和一个交互网页；图片与模型引用均可解析。
- 已通过本地 HTTP 服务和 Chrome headless 实际检查静态首屏、三阶段与类别样本切换、3D 加载，以及模拟 3D 错误后的静态兜底，并保存了本机截图。
- 用户在取消自动切换 3D 后确认静态画面可以看到；本机检查显示静态首屏保持可见至少 24 秒。
- Wuji2 手物对照核对了 48 个阶段、11,520 张 WebP（含离线视角网格）和 192 个 GLB；抽样重载手物/纯手型 GLB 分别有 2/1 组几何，浏览器中检查了四图可见及筛选后图片和链接同步更新。
- 独立纯手型版本核对了 16 例、5,760 张 WebP、96 个仅含手部的 GLB，6,048 个索引资源引用均存在；禁用 WebGL 的 Chrome 在实际 HTTP 页面验证默认样本、三个旋转控件及双图同步。

## 已知限制

- 现有 USD 输出按样本串接时间轴，缺少分类总览、元数据筛选和物体导航。
- 现有 OBJ 输出偏向单样本诊断，不适合作为 31 类浏览产品。
- 数据集有 31 类而不是完整 33 类。
- Wuji2 已有 Shadow/Allegro 双来源的 16 条固定开发样本与批量报告，见[开发样本](../../design/wuji2-benchmark.md)；三阶段姿态可运行，但仍有较大穿透，六方向评估 0/16 通过，尚无无碰撞或稳定抓取结果。旧演示脚本仍不在工作区。
- 纯手型拟合将平均归一化动作误差从 0.530 降至 0.083，但抓取阶段世界指尖均距从 1.73 mm 增至 55.45 mm；42/48 个阶段求解器收敛，76/960 个关节位置距限位小于 0.001 rad。该版未做物体接触或稳定性评估，实时 WebGL 页面模式本轮也未单独验收。
- 用户侧确认静态画面可见，并报告浏览器无法创建 WebGL 画面。页面已支持三组箭头控制的预渲染多视角；用户对三方向版本给出正面反馈，但没有逐项验收记录。当前只导出了 31 类中的 3 类。
