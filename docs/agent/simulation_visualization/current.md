# 仿真与可视化当前总览

当前原型的用户侧显示问题、未完成项和后续顺序见[项目交接文档](../../../HANDOFF.md)。

## 当前能力

- [MuJoCo 环境](evolution/mujoco-environment.md)：代码支持模型装配、运动学、接触、优化和评估。
- [31 类图鉴](evolution/grasp-taxonomy-visualization.md)：3 类 × 3 样本原型已有 27 个 GLB 和 27 张三阶段真实渲染图片，本机浏览器已检查首屏、切换和故障兜底。

## 当前证据

- `vis_3d` 和 `vis_usd` 的代码路径已阅读。
- MuJoCo Menagerie 子模块已于 2026-09-25 恢复到固定提交，Shadow 网格存在。
- 项目内 `.viz-env` 已安装最小渲染依赖，真实 Shadow 场景加载成功。
- 已生成 27 个 GLB、27 张 PNG、一个 JSON 索引和一个交互网页；图片与模型引用均可解析。
- 已通过本地 HTTP 服务和 Chrome headless 实际检查静态首屏、三阶段与类别样本切换、3D 加载，以及模拟 3D 错误后的静态兜底，并保存了本机截图。
- 用户在取消自动切换 3D 后确认静态画面可以看到；本机检查显示静态首屏保持可见至少 24 秒。

## 已知限制

- 现有 USD 输出按样本串接时间轴，缺少分类总览、元数据筛选和物体导航。
- 现有 OBJ 输出偏向单样本诊断，不适合作为 31 类浏览产品。
- 数据集有 31 类而不是完整 33 类。
- Wuji2 交接样例只证明运动学拟合，不证明无碰撞或抓取稳定。
- 用户侧只确认了静态画面可见，并报告浏览器 3D 似乎无法显示。页面现有 WebGL 检查、渲染帧检查和 GLB 下载入口，但用户侧复测尚未完成；当前只导出了 31 类中的 3 类。
